# Plugin Template

Use this as your starting point when building a new plugin.

## How to get started

1. **Copy this folder** — duplicate `plugin-template/` and rename it to your plugin's name (e.g. `word-counter`).
2. **Edit `plugin.json`** — change the `name`, `description`, and your author details.
3. **Write your code in `index.js`** — the `execute()` function is where your plugin does its work.
4. **Test it** — run it locally and make sure it does what you expect.
5. **Share it (optional)** — when it is ready, move the folder to `marketplace-submissions/`.

## Files in this template

| File | What it does |
|---|---|
| `plugin.json` | Describes your plugin (name, version, author, etc.) |
| `index.js` | The actual code that runs when someone uses your plugin |
| `README.md` | This guide — replace it with your own description when you are ready |

## Naming rules

- Use only lowercase letters, numbers, and dashes
- No spaces (use `word-counter`, not `Word Counter`)
- Keep it short and descriptive
