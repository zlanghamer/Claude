# Changelog

Track the projects you create and changes you make over time.

## What to Record

- New plugins, skills, or hooks created
- Updates you make
- Projects submitted to marketplace
- Lessons learned

## Format

```
## [Date] - [Project Name]
- What you created
- Brief description
```

## Examples

```
## 2026-03-14 - My First Plugin
- Created a code formatter plugin
- Submitted to marketplace for review

## 2026-03-15 - Bug Fix in Code Formatter
- Fixed indentation issue
- Updated to version 1.0.1
```
