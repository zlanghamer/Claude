# My Claude Code Projects

Welcome! This is your personal GitHub home for all Claude Code projects: plugins, skills, hooks, and more.

## What's Here?

| Folder | Purpose |
|--------|---------|
| **plugins/** | Your custom mini-tools and utilities |
| **skills/** | Things you teach Claude to do |
| **hooks/** | Code that runs automatically |
| **templates/** | Copy-paste starters for new projects |
| **experiments/** | Test ideas here (no pressure) |
| **marketplace-submissions/** | Projects ready to submit |
| **docs/** | Guides and your learning notes |
| **marketplace/** | Official Anthropic plugin marketplace info |

## Getting Started

### Creating Your First Project

1. **Read:** Pick what you want to create:
   - Plugin? → Read `docs/HOW_TO_CREATE_PLUGINS.md`
   - Skill? → Read `docs/HOW_TO_CREATE_SKILLS.md`
   - Hook? → Read `docs/HOW_TO_CREATE_HOOKS.md`

2. **Copy:** Use the templates in `templates/`
   - Copy the template folder
   - Paste into the right folder (plugins/, skills/, or hooks/)
   - Rename it to your project name

3. **Customize:** Edit the three files:
   - `[type].json` - Configuration
   - `index.js` - Your code
   - `README.md` - Instructions

4. **Test:** Make sure it works

5. **Submit:** When ready, move to `marketplace-submissions/`

## Understanding the Folders

### plugins/
Your personal plugins - small tools you create. Examples:
- Code formatter
- File organizer
- Text processor

### skills/
Teaching Claude new abilities. Examples:
- Company coding style guide
- Industry-specific knowledge
- Special problem-solving techniques

### hooks/
Automatic triggers that run without you asking. Examples:
- Auto-check code when you save
- Auto-format when you paste
- Auto-notify when tasks complete

### templates/
Ready-to-use starting points:
- `plugin-template/` - Copy for new plugins
- `skill-template/` - Copy for new skills
- `hook-template/` - Copy for new hooks

### experiments/
Safe testing ground:
- Try new ideas here
- No pressure to finish
- Move to proper folder when ready

### marketplace/
Official Anthropic Claude Code marketplace:
- Central plugin registry
- Quality guidelines
- Submission process
